## Comandos y alcance

- `npm run build`: build estándar, gate desactivado por defecto. Build de QA: `PUBLIC_GTM_ID=GTM-TB7F773D PUBLIC_GA_ID=G-XQMPJG8B08 PUBLIC_GTM_PHASE1_READY=true PUBLIC_ANALYTICS_ENV=test npm run build`. Solo artefacto local, sin despliegue.
- `npm run check:types`: Astro estricto de `src/**/*` con `tsconfig.web.json`, heredando aliases/strict del tsconfig vigente. La primera invocación global de `astro check` sin alcance terminó `Killed` al recorrer `studio/dist` generado; se considera inconclusa, no un fallo heredado probado. No se ha relajado strict ni cambiado tipos de aplicación. Comprobación equivalente de fuentes web sobre archive de commit base con mismas dependencias: también cero errores. Los números de ficheros no sustituyen aceptación funcional.
- `npm run check:visibility -- http://127.0.0.1:4325 --negotiation skip`: servidor Astro local. El comando exige URL; una invocación inicial sin argumento no era una prueba válida. No acredita Link headers/rewrites/negociación de Vercel; repetir tras despliegue.
- `npm run check:favicons`. Smoke adicional del build estándar con consentimiento completo: cero cargas GTM/GA/TikTok/Meta; `evidence/default-build-smoke.json` confirma gate desactivado.
- `npm run test:analytics`, `npm run test:analytics-runtime`, `npm run test:collaborators`, `npm run test:search-tracking`, `npm run test:search-intent`, `npm run test:booking`, `npm run test:public-trip` y `npm run check:analytics-recipe`.
- `npm run test:analytics-browser`: requiere Chromium/Playwright del operador y servidor **local estático de build QA**. Configurar `ANALYTICS_TEST_URL`, `PLAYWRIGHT_MODULE` y `CHROMIUM_PATH` si no están instalados en rutas estándar. En esta máquina se usó Playwright 1.50.1 existente, Chromium 1228, bibliotecas extraídas en `/tmp/th-browser-deps` (sin instalación del sistema) y servidor `python3 -m http.server 4326 --bind 127.0.0.1 --directory dist`. Las rutas del test aplican los headers de seguridad de `vercel.json`, sustituyen GTM por stub, bloquean terceros y previenen navegación externa. **No ejecutar contra producción.**
